## Task

Run the `scripts/generate_pkl_highlightjs.py` script to generate the `pkl.js` file that defines a function accepting a `hljs` reference and returning a language object for Pkl. This file should be placed in `src/languages/pkl.js`.

## Acceptance Criteria

- [x] The `scripts/generate_pkl_highlightjs.py` script is executed successfully.
- [x] A new file `src/languages/pkl.js` is generated by the script.
- [x] The generated file contains an `module.exports = function(hljs) { ... }` structure.
- [x] The generated file's returned object includes `name: "Pkl"` and basic `keywords` and `contains` properties.
